SIGMA LAB MULTI-PAGE WEBSITE

Pages included:
- index.html: Home
- about.html: About SIGMA Lab
- research.html: Research directions
- projects.html: Research projects and funded research
- people.html: Principal Investigator profile
- tools.html: Computational tools and web servers
- publications.html: Selected publications
- contact.html: Contact and collaboration information

HOW TO PREVIEW
1. Extract the ZIP while keeping the folder structure intact.
2. Open index.html in a modern browser.
3. Use the navigation menu to visit each separate page.

The website is static HTML/CSS/JavaScript and can be hosted on a static web host or an institutional server. Internet access is needed for the Google Fonts and external links. Review all content, funding details, contact information, links, and institutional web policies before publishing. The Publications page includes linked Google Scholar, ORCID, and ResearchGate profile icons, plus selected publications from 2022–2025 based on the supplied CV. Review bibliography details before publishing.

Navigation update: About and Research content are combined on research.html under “Research Themes”. The old about.html redirects to research.html.

Official uploaded logos are displayed in each page header: ICAR left, ICAR-IASRI right.
